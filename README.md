# 🎮 Catcher Game using Python

The Catcher Game is a simple 2D arcade game built with Python and the Pygame library. In this game, the player controls a catcher (like a basket) and must catch falling objects to score points. It's a fun and interactive way to learn the basics of game development and Python programming.

## 🧩 Features:

- Real-time player movement using keyboard controls
- Falling objects (e.g., fruits, balls) generated randomly
- Score tracking and display
- Game over condition when objects are missed
- Sound effects (optional)
- Easy to understand and extend for beginners

## 🛠️ Technologies Used:

- **Python 3**
- **Pygame**

## ▶️ How to Run the Game:

1. Make sure you have Python and Pygame installed:

```bash
pip install pygame
2.Clone the repository or download the source code.
3.Navigate to the project directory and run:
python catcher_game.py
#Replace catcher_game.py with your actual main Python file name.
